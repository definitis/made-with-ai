# E-com AI Manager

**Status:** source currently private

A staged project for building AI-assisted product-card management workflows from real marketplace exports rather than synthetic toy data.

## Current capabilities

- Import from CSV, JSON and XLSX.
- Normalize wide/irregular spreadsheet structures into a common product model.
- Produce missing-data and profile reports.
- Build examples of manager actions from real data.
- Generate baseline action plans for comparison.
- Evaluate generated actions against historical manager behavior.
- Build a real test pack for human review.
- Generate dry-run SEO titles, descriptions, keywords and characteristics.
- Generate designer/photo briefs with warnings about missing materials.

## What it demonstrates

- Turning messy operational data into a machine-usable contract.
- Separating data ingestion, evaluation and generation instead of jumping directly to prompts.
- Building a review loop around AI output.
- Using real examples to measure whether an agent is useful.
- CLI-first development that is testable before adding unnecessary UI.

## AI-assisted development

AI was used for architecture, implementation, data-model iteration, CLI work, evaluation tooling, tests and documentation. The project also explores where deterministic preprocessing and evaluation are more important than simply increasing model capability.
